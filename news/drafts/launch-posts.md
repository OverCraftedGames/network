# OCG+ is now a monthly loot drop

OCG+ has been rebuilt around loot. Pick one of three tiers and get a drop every month, on every OCG server:

- **OCG+ I**: $10 a month
- **OCG+ II**: $20 a month
- **OCG+ III**: $30 a month

Every drop includes crate keys, Credits and that month's cosmetic. Higher tiers get more of everything, plus extras like plushies. See exactly what each tier gets at <https://minecraft.ocgames.xyz/plus.html>

Perks like extra homes and commands now come from **network ranks**. Ranks are permanent, work on every server, and stack with OCG+.

You can cancel any time from your Tebex payment history, and anything you've already received stays yours.

# Welcome to OCG Network

CarbonCraft is now **OCG Survival**, the first server on **OCG Network**: the home for every Minecraft server we run at OverCrafted Games.

How you play doesn't change. It's the same world, the same economy, the same community and the same address: `play.carboncraft.xyz`

Have Carbon+ or CarbonCoins? We'll post exactly what happens to them before anything changes in game.

OCG Skyblock is in development. More on that soon.
